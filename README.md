# RMS Premier Services

Modern, responsive web presence for **RMS Premier Services** — Healthcare & IT Project Management Consulting.

## Features
- **PMP® Certified Consulting Showcase**: Healthcare IT, EHR integration, technical writing, and workflow optimization.
- **Custom Vector Branding**: Embedded SVG vector logos (`logo.svg`, `logo-icon.svg`, and `logo-light.svg`).
- **Responsive Modern UI**: Dark-mode executive design with glassmorphism, micro-animations, and mobile navigation.

## Project Structure
- `index.html` - Main landing page structure and semantic markup
- `style.css` - Custom design system, typography, and layout styles
- `logo.svg` - Horizontal brand logo with R-M-S monogram emblem
- `logo-icon.svg` - Square brand icon and favicon
- `logo-light.svg` - Document / light-background logo
- `hero.png` - Hero section imagery
